# Erick Coffee ☕

یه وب‌سایت کافی‌شاپ که با HTML، CSS، Tailwind و Swiper ساخته شده.

## 🛠 تکنولوژی‌ها
- HTML5
- CSS3
- Tailwind CSS
- Swiper
- Vite

## 📄 صفحات
- `index.html` — صفحه اصلی
- `login.html` — صفحه ورود

## 🚀 نحوه اجرا
1. پروژه رو کلون کن
2. `npm install`
3. `npm run dev`
